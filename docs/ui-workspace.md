# 双栏工作区界面约定

用户确认日期：2026-10-29。

- 参考朝朝 claw 的信息布局：宽屏将功能入口与会话列表合并为左栏，右栏展示内容，不再同时展示主导航、列表和详情三栏。
- 在左栏集中展示邮件、人际关系、日历、RSS、技能、知识市场等入口。点击后进入相应列表，提供“返回工作入口”；列表选择在右侧展示详情。窄屏按入口、列表、详情层级返回。
- 主侧栏功能入口的点击高度为至少 48 个平台逻辑单位，文字约 14，桌面图标约 18、触屏图标约 20；入口区可滚动，同时为会话列表保留空间。
- 以 Android ConnorTheme.kt 为配色来源：品牌黄 #FFD84D；浅色强调 #715600 / 白字，深色强调 #FFD84D / #101820；容器 #FFF3C4 / #544400，基础背景 #F6F6F7 / #141416。错误和警告仍使用语义颜色。
- 使用用户确认的欢迎、空状态和完成配图，资源随本客户端发布。配图由内置图像工具基于康纳头像生成，图片中不包含提示语。
- 保留康纳同学的身份和陪伴式提示语风格。布局变化时修正左侧、右侧等方向指引。
- 复用原有数据服务与权限流程；不改变邮件发送确认等行为。

## 按钮分组

桌面新建和普通操作组采用 40 的高度，工具栏、输入区和图标按钮采用 36，功能导航入口保留 48。触屏普通操作保留至少 48 的触控高度。同组主次操作应使用相同高度、圆角与间距，不能因强调色不同改变尺寸。
